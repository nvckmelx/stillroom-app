# Как добавлять музыку и менять сайт

Админка: `https://ВАШ-ДОМЕН/admin`. Работает и с телефона: меню открывается кнопкой ☰, кнопки сохранения всегда внизу экрана.

## Главное правило: черновик → превью → публикация

| Кнопка | Что происходит |
|---|---|
| **Save draft** | Сохраняет. Если трек уже опубликован, посетители продолжают видеть старую версию. |
| **Preview** | Сохраняет черновик и открывает сайт с вашими изменениями. Видите только вы (пока вошли в админку). Жёлтая полоса сверху = режим превью. |
| **Publish / Publish changes** | Изменения становятся видны на сайте и в Android-приложении в течение минуты. Пересборка не нужна. |
| **Unpublish (hide)** | Трек исчезает с сайта и из приложения, но остаётся в админке. Можно опубликовать снова. |
| **Discard unpublished changes** | Отменяет черновик, возвращает опубликованную версию. |

## Добавить трек

1. **Tracks → + New track.**
2. **Title** — название. **Short line** — строка на карточке («Rain · 8 h»). **Details** — мелкая техническая строка
   в комнате прослушивания («432 Hz · binaural»). **Description** — текст на странице трека.
3. **Category** — вкладка в комнате прослушивания и раздел каталога. **Tags** — отметьте нужные или впишите новые через запятую.
4. **Sound → Upload audio**: MP3, M4A/AAC, OGG/Opus, WAV, FLAC (до 60 МБ по умолчанию). Длительность определяется сама.
   Для длинных треков лучше MP3 128–192 kbps: 1 час ≈ 55–85 МБ, поэтому часовые треки лучше делить или поднять лимит.
   **Built-in sound** — одна из 33 генеративных мелодий; играет, если файла нет (и как запасной вариант, если файл не загрузился).
5. **Cover** — необязательно (JPG/PNG/WebP). Без обложки используется анимированная сцена.
6. **Background scene** — живой фон трека: выберите одну из 33 сцен.
7. **Address & SEO** (свёрнуто) — адрес страницы `/track/…`, SEO-заголовок и описание. Можно не трогать.
8. **Preview** → проверить → **Publish**.

Порядок треков: **Tracks** → перетащите за ⋮⋮ (компьютер) или стрелки ↑ ↓ (телефон) → **Save order**. Порядок применяется сразу.

## Подборки (Collections)

**Collections → + New collection**: название, описание, обложка, отметьте треки и расставьте стрелками.
Публикация как у треков. Чтобы подборка была на главной — добавьте её в **Home page**.

## Главная страница (Home page)

Заголовок, подзаголовок, текст кнопки и трек, который она запускает. Ниже — **Sections** в порядке показа:
ряд подборки, сетка категорий, избранные (Featured) треки, список всех треков. Добавляйте, удаляйте, двигайте стрелками.
Save draft → Preview → Publish.

## Название, логотип, ссылки, SEO (Site & SEO, только admin)

- **Site name** — когда выберете финальное имя (Stillroom Music, LumaHush, Velune Sound, Driftora, Somnora Music…),
  поменяйте здесь: обновятся заголовки страниц, логотип-текст, PWA-название, SEO. Доступность доменов я **не проверял**.
- **Logo** — PNG/WebP с прозрачностью, ~28 px по высоте на сайте.
- **Footer note**, **About**, **Links** (Instagram, YouTube, email через `mailto:`).
- **Default title/description**, **Sharing image** 1200×630 — то, что видно в Google и при отправке ссылки.

## Категории и теги

**Categories**: название, «Eyebrow text» (маленькая строка над названием трека в комнате прослушивания), описание,
адрес, видимость, порядок. Изменения категорий и тегов применяются **сразу** (без черновика).
Категорию с треками удалить нельзя — сначала перенесите треки.

## Пользователи

**Users** (только admin): добавить редактора (роль `editor` — треки, подборки, категории, теги, главная;
без пользователей, настроек сайта и бэкапов), сменить роль, отключить, задать пароль. Свой пароль — **Account**.
После 5 неудачных входов за 15 минут вход временно блокируется.

## Если что-то пошло не так

- «The file is larger than the server allows» → поднимите лимиты (см. DEPLOY-HOSTINGER.md, раздел 5).
- «This file does not look like a real MP3» → файл повреждён или это другой формат с чужим расширением; пересохраните.
- Трек не появился в приложении → оно обновляет каталог при запуске и раз в 5 минут; закройте и откройте приложение.
- Нужно откатить всё → Backups → скачайте нужную копию и восстановите (раздел 7 инструкции по выкладке).
